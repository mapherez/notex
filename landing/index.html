Good to know

Before you get started.

Do I need an account or internet connection?

The desktop app works without an account, including offline writing, searching, and exports. Browser mode requires a Google account; downloaded notes can be edited offline after the app and notes have been cached. Backups resume when you reconnect.

How do I install NoteX?

On a Windows PC or Mac, select Download to get the desktop installer. On a tablet or phone, select Open NoteX Web to use NoteX in your browser, with no installation needed. Read the installation guide →

Can I use NoteX on a tablet or phone?

Yes. Open the web app in your browser and sign in with Google. The interface adapts to touch screens; on phones, use portrait orientation. Read the tablet and phone guide →

Can I move or back up my notes?

Yes. On desktop, export a complete workspace with its attached files as a .notex package, or a single note as .notex-note. A full-workspace import replaces the current library. Signing in with Google automatically backs up your account library to Drive. Read the import and backup guide →

Is AI required to use NoteX?

No. Local MCP is optional and starts only when you enable it. It connects compatible clients to your library while NoteX is open. Content read by an AI client is subject to that client's own privacy settings.
