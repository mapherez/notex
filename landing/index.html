The workspace

Made for knowledge you return to.

NoteX combines flexible writing with enough structure to keep growing collections useful over time.

01

Block-based notes

Build each note from ordered content blocks with individual titles and rich text.

02

Rich content

Use headings, lists, tables, links, colors, highlights, images, and attachments.

03

Search across context

Find matches across note headers, blocks, tags, and collections, ranked by relevance.

04

Organize naturally

Combine tags, collections, favorites, pins, recent activity, and trash.

Local MCP

Let compatible AI clients work with your notes.

Start the embedded MCP server from Profile, copy the generic connection details, and use supported AI clients to search, read, create, and edit notes.

  • No NoteX account or cloud synchronization
  • Available only while NoteX and MCP are running
  • Local Streamable HTTP connection on your computer
