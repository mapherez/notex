Privacy Policy

How NoteX handles local data, Google Drive backups, and optional AI access.

English

NoteX stores desktop libraries in local SQLite databases and browser libraries in IndexedDB on your device. Local libraries are kept separate for each Google account.

Desktop use does not require an account. Browser mode requires Google sign-in. NoteX uses your Google account ID, email, display name, and profile image to identify your account and library.

When connected to Google, NoteX sends note JSON, library metadata, and attachments directly to the application's hidden data area in your own Google Drive. Google processes this data under its own policies. Your notes and Google tokens are not stored on a NoteX server.

Desktop refresh tokens are stored using the operating system credential store. Browser access tokens are kept in session storage until logout or expiry. Signing out preserves local account libraries; clearing browser site data can remove local notes and pending backups.

The public website and webapp host receive normal HTTP requests and may record connection information in server logs. Google sign-in, Drive access, release checks, and downloads require internet access.

When you start local MCP and connect an AI client, note data requested by that client is sent through the local MCP connection. NoteX does not store an additional copy of that exchange, but the connected AI client may process the content under its own privacy policy.

When you export your data, NoteX creates a `.notex` package locally with your database and attached files. You are responsible for where you store or share that exported package.

When you import a package, NoteX replaces the current local database and files folder with the selected `.notex` package.

NoteX does not sell your data or use your notes for advertising. Data is transferred to Google or a connected AI client only through the corresponding features described above.

Português

O NoteX guarda bibliotecas desktop em bases SQLite locais e bibliotecas web em IndexedDB no seu dispositivo. As bibliotecas locais são separadas por conta Google.

A utilização desktop não requer conta. A versão web requer login Google. O NoteX utiliza o ID da conta Google, email, nome e imagem de perfil para identificar a conta e a biblioteca.

Quando ligado à Google, o NoteX envia JSON das notas, metadados da biblioteca e anexos diretamente para a área oculta da aplicação na sua própria Google Drive. A Google processa estes dados segundo as suas políticas. As notas e os tokens Google não são guardados num servidor do NoteX.

Os refresh tokens desktop são guardados através do gestor de credenciais do sistema operativo. Os access tokens web ficam no armazenamento de sessão até logout ou expiração. Terminar sessão preserva as bibliotecas locais da conta; limpar os dados do site no browser pode remover notas locais e backups pendentes.

O website público e o host da webapp recebem pedidos HTTP normais e podem registar informação de ligação nos logs do servidor. Login Google, acesso à Drive, procura de atualizações e downloads requerem internet.

Quando inicia o MCP local e liga um cliente de AI, os dados das notas pedidos por esse cliente são enviados através da ligação MCP local. O NoteX não guarda uma cópia adicional dessa troca, mas o cliente de AI ligado pode processar o conteúdo de acordo com a sua própria política de privacidade.

Quando exporta os seus dados, o NoteX cria localmente um pacote `.notex` com a sua base de dados e os ficheiros anexados. É da sua responsabilidade decidir onde guarda ou partilha esse pacote.

Quando importa um pacote, o NoteX substitui a base de dados local e a pasta de ficheiros atuais pelo pacote `.notex` selecionado.

O NoteX não vende os seus dados nem utiliza as suas notas para publicidade. Os dados são transferidos para a Google ou para um cliente de AI ligado apenas através das funcionalidades correspondentes descritas acima.
