# Notes & blocks

A note is a container for related information. Its title and subtitle describe the whole subject; blocks let you divide the content into useful sections.

## Build a structured note

Instead of keeping everything in one long body, give each section a block and a descriptive title. A project note might contain **Overview**, **Decisions**, and **Next steps**. A recipe might use **Ingredients**, **Method**, and **Variations**.

You can still use headings inside a block. Block titles are especially useful when you want to move an entire section or jump to it from the side navigation.

## Reorder blocks

Drag a block by its reorder handle to move it to another position.

For keyboard control:

1. Click the reorder handle, or reach it using **Tab**.
2. Press **Up** to move the block one position earlier, or **Down** to move it one position later.
3. Repeat as needed. The handle keeps focus and the page follows the moved block so it stays in view.

The first block cannot move farther up, and the last block cannot move farther down. Clicking the handle gives it keyboard focus without removing drag-and-drop behavior.

## Navigate a long note

The navigation beside the note lists its blocks. Use a block's entry to jump to that section. The navigation stays below the top bars while you scroll.

Clear titles make this more useful than a list of generic section names. You can rename a block as its purpose changes.

## Choose a thumbnail

Use the note's thumbnail button to open the picker. To use it from the keyboard, focus the button and press **Enter**. The first thumbnail receives focus immediately.

Use the arrow keys to move around the grid and **Enter** to select. **Escape** closes the picker and returns focus to the thumbnail button.

## Remove content carefully

Deleting a block removes that section of the note. If it contains stored images or attachments, deleting the whole block also removes its associated files from local storage.

Export a note before making changes you might want to keep separately. [Single-note packages](import-export.md#export-one-note) include the note's attached files.
