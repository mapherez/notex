# Formatting & files

Use the editor toolbar to make a note easier to read, rather than giving every kind of information the same appearance.

## Format text

NoteX supports bold, italic, underline, strikethrough, inline code, links, text colors, and highlights. Block content also supports headings, alignment, quotes, code blocks, and horizontal rules.

Select text before applying formatting to existing content. You can also choose a format and continue typing with it. Note and block headers support inline formatting too.

## Lists and checklists

Use bullet lists for related items, numbered lists for steps, and checklists for work that needs tracking.

Press **Enter** to continue a list. Pressing **Enter** in an empty list item exits the list. The app's **Profile → Shortcut Help** includes editor shortcuts and list triggers.

## Tables

Tables work well for information that benefits from rows and columns: comparisons, measurements, inventories, or short reference lists.

Insert a table through the editor controls. Table actions let you change the structure as your content grows. You can navigate the table-action menu with the keyboard as well.

On a smaller screen, scroll horizontally within a wide table to see the remaining columns.

Keep very long prose in ordinary blocks so it remains comfortable to read.

## Images and attachments

Add images or files using the editor controls. Inline images can also be added by dragging and dropping them into the editor.

Resize an inline image while keeping its proportions, or open it for a larger preview. In the preview, pinch to zoom on a touch screen and drag a zoomed image to inspect it.

NoteX stores imported files with the local library. Opening an attachment uses its stored copy, so it does not depend on the original file remaining in your Downloads folder.

Deleting an image or attachment from a note also removes its stored file and database reference. Exported note and workspace packages include attached files; see [import and export](import-export.md).

## Paste formatted content

NoteX supports rich paste for compatible content. Formatting from another app or website is adapted to the editor's supported features; a pasted document does not necessarily keep the original page layout.

If a complex paste is difficult to read, simplify it into titled blocks, lists, or a table.
