# Search & filters

Use global search when you remember part of a note's content. Use filters when you know where it belongs or want to browse a smaller group.

## Global search

Press **Ctrl + F** to focus the search field. Search can match note titles, subtitles, block titles, block content, tags, and collections.

Words are treated as independent search terms. A note can appear when it matches any term, with notes matching more distinct terms ranked first. Where the match appears and the note's update time also help determine the order.

For example, searching for `release checklist` can find notes that mention either word; notes matching both are ranked ahead of notes matching only one.

## Open a result

Use **Up** and **Down** to move through search results, then **Enter** to open the highlighted result. **Escape** closes the search results.

A descriptive subtitle or block title can make a result easier to recognize when several notes cover the same subject.

## Filter the note list

The note list includes tag and collection selectors. Combine them when you want notes from one collection with a particular tag.

Reset selectors to **All tags** and **All collections** to return to the broader list.

## Change sorting and view

Use the ordering selector to choose the list's sort order. Switch between **List** and **Grid** depending on whether you prefer compact rows or cards.

Pinned notes retain their separate section and manual order. The recent-notes list follows actual edit timestamps rather than opening activity.

## Navigate selectors by keyboard

Focus a dropdown with **Tab** and press **Enter** to open it. Use arrow keys to navigate and **Enter** to select. Selecting an item or pressing **Escape** closes the dropdown and returns focus to its trigger.

Searchable selectors also let you type to narrow the available options. See [shortcuts and focus](keyboard.md) for more keyboard workflows.
