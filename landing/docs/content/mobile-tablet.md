# Tablet & phone use

NoteX 2.4.0 adapts the browser app to tablets, phones, and smaller desktop windows. The Windows installer remains for desktop; on a tablet or phone, open the [web app](https://notex.mapherez.com/app/) in your browser and sign in with Google. Browser mode requires an account and internet access for the first visit and for notes that have not yet downloaded.

## Navigate on a smaller screen

Use the menu button in the top bar to open the main navigation. When viewing a note, use the note details button to open its information, tags, links, files, and other side-panel content. The panels can be closed with their close button or by swiping them away.

The note editor toolbar adapts to the available width and stays usable when the on-screen keyboard opens. Tables and other wide content can scroll horizontally instead of forcing the entire page wider.

## Move and manage blocks by touch

Press and hold a block, then drag it to a new position. A compact preview and drop indicator show where it will land. Release to place it; if you keep holding without dragging, a menu offers **Move block up**, **Move block down**, and **Delete**. The move actions are useful when dragging is difficult.

For keyboard use, focus the block's reorder handle and press **Up** or **Down**. See [notes and blocks](blocks.md#reorder-blocks) for more detail.

## View images and attached files

Open an inline image for a larger preview. On a touch screen, pinch to zoom and drag a zoomed image to inspect it. Images keep their proportions when resized. Attachments and images are managed from the note editor and note details; see [formatting and files](rich-content.md#images-and-attachments).

## Phone orientation and offline work

Use a phone in portrait orientation. If you turn it to landscape, NoteX shows a notice asking you to rotate back before continuing.

Downloaded notes can be edited offline after the production web app and required notes have been cached. Pending changes back up to Google Drive when the connection and authorization return. A first visit or an undownloaded note still needs internet access. See [Google Drive and browser mode](google-drive-web.md#refresh-and-offline-work) for details.

Local MCP and full-workspace import/export are desktop features. To make a separate portable backup, use the Windows app's [export controls](import-export.md).
